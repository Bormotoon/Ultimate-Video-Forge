# Manual acceptance evidence

Automated checks cannot close tasks that require a real recording or NLE
application. Store dated results here without committing the source media.

## Phase 0 recording

Select a private 20-40 minute recording with two cameras and an external
recorder. Record its local path, duration, camera models, recorder model, frame
rates, and audio layout in an untracked `real-recording.local.yaml` file. Do not
copy the media into this repository.

## NLE imports

For each acceptance run, copy `nle-import-template.md`, record the exact Final
Cut Pro and Premiere Pro versions, and complete every item. Phases 2-4 remain
open until both applications have signed-off evidence.
